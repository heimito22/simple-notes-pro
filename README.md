# Simple Notes Pro

Bloco de notas minimalista para Android e Windows, com backup automatico no Google Drive, IA, pastas, alarmes e bloqueio por biometria.

## Downloads

Veja a pagina de [Releases](../../releases) para baixar a versao mais recente:

- **Windows** — Instalador (Setup) e Portatil
- **Android** — via [Play Store](https://play.google.com/store/apps/details?id=com.seuusuario.simplesnotes)
